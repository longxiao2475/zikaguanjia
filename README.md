# 字卡管家

## 一、产品定位与简介

**名称**：字卡管家  
**类型**：微信小程序（个人主体）  
**定位**：面向幼儿园阶段孩子家长的个人字卡复习管理工具  

**简介**：字卡管家帮助家长用语音、手输等方式快速记录孩子学过的字/词卡，并根据熟练度和遗忘周期自动排出每日待复习清单。在认字日，系统会提醒家长今天该认哪些字，帮助家长守住认字节奏。整个过程由家长操作完成，孩子不需要碰屏幕，专注与实体字卡进行互动。认字时，家长可以点开任意字卡查看组词，便于讲解和引导。  

**核心价值**：记录只是手段，真正卖的是“替家长做复习调度 + 守住认字节奏”——家长无需自己判断今天该抓哪几个字，到点提醒能有效避免漏练，孩子的进步也更容易被看见。  

## 二、目标用户

- 幼儿园阶段孩子的家长  
- 希望在日常生活中高效陪伴孩子认字、复习字卡的人  
- 更希望“少操心、稳推进”的家长群体  

## 三、核心功能

- 快速记录已学字卡和词卡  
- 支持语音输入、手输等多种记录方式  
- 根据熟练度与遗忘周期自动生成复习计划  
- 每日提醒家长今日应复习内容  
- 支持查看字词的组词信息，方便讲解  
- 以“实体字卡互动”为主，降低孩子使用屏幕的依赖  

## 四、产品愿景

让家长不再为“今天该复习哪些字”而焦虑，把更多精力放在亲子互动与孩子成长上。
