## 一、设计原则

基于用户硬约束（原话）："设计得易于操作、简洁，不然用户会不知道怎么操作。"

| 原则 | 落地方式 |
|------|---------|
| 低认知负担 | 每屏一个焦点，打开就知道做什么 |
| 少步骤 | 录入两步存（说→存）、复习点一下标好 |
| 大按钮单手可达 | 主操作在底部，拇指够得到，语音按钮 120px |
| 无隐藏菜单 | 所有功能可见，看到什么点什么 |
| 无复杂交互 | 不用手势、不用长按菜单、不用滑动删除 |

## 二、信息架构

```
底部 Tab 导航（3个）
├── 首页（默认页）
├── 字卡库
└── 设置

独立页面（从首页/字卡库进入）
├── 录入页（语音/手输入）
└── 复习页（今日清单 + 标熟练度 + 组词）

弹层组件（不跳页）
├── 组词面板（bottom sheet，复习页+字卡库共用）
├── 编辑字卡面板（bottom sheet，字卡库）
└── 订阅授权卡片（复习完成后弹出）
```

## 三、页面说明

### 3.1 首页

**定位**：打开即知道今天做什么——认字日提醒 + 待复习清单 + 快捷入口

**页面结构（从上到下）**：
1. **顶部问候区**（渐变背景）：问候语 + 日期 + 是否认字日
2. **被动兜底提醒 banner**（认字日+有待复习时显示）："今天该认字啦 / 今日重点 N 个字" + 去复习按钮。永远不断，不依赖订阅额度。
3. **学习概览卡片**（3列）：总字数 / 已掌握 / 待复习
4. **提醒额度预警 banner**（额度≤2时显示，正常隐藏）："提醒额度仅剩 N 次，完成复习可补充" + 去补充按钮
5. **今日待复习清单**：按优先级排序，红/黄/绿圆点代表不熟/一般/熟练，点击进入复习页
6. **快捷操作按钮**：录入新字（语音为主，主色按钮）/ 开始复习
7. **右下角浮动按钮**：快速录入入口

**交互**：
- 点击清单项或"开始复习" → 复习页
- 点击"录入新字"或浮动+ → 录入页
- 点击额度预警 banner → 触发订阅补充

### 3.2 录入页

**定位**：说完就存，两步搞定

**页面结构**：
1. **顶部导航**：返回 + 标题"录入字卡"
2. **录入方式 tab**：语音录入（默认）/ 手动输入
3. **语音模式**：
   - 120px 大圆按钮（渐变主色+阴影），按住说话，松开识别
   - 提示文字"说一个字或词，一次一个"
   - 识别结果展示区（确认框），显示识别出的字/词
4. **手动模式**：
   - 输入框 + 提示文字
5. **字卡来源开关**：新学（默认）/ 已学过
   - 新学 → 默认熟练度"不熟"
   - 已学过 → 默认熟练度"一般"
6. **保存按钮**：底部大按钮

**交互**：
- 按住大圆按钮 → 语音识别 → 显示结果 → 确认 → 选来源 → 保存
- 切换到手输 tab → 输入字/词 → 选来源 → 保存
- 去重：同字/词已存在则提示合并/跳过

### 3.3 复习页

**定位**：陪孩子时只管标，不刷屏

**页面结构**：
1. **顶部导航**：返回 + 标题"今日复习"
2. **复习头部**（渐变背景）："今日待复习 N 个字" + 不熟/一般/熟练分布
3. **字卡列表**（逐张展示）：
   - 每张卡：字/词（大字）+ 优先级标签 + 元信息（类型/熟练度/距上次复习天数/复习次数）
   - 字/词可点击 → 弹组词面板（bottom sheet）
   - "查看组词 ›" 按钮 → 同样弹组词面板
   - 底部三个大按钮：不熟 / 一般 / 熟练
4. **完成复习按钮**（底部大按钮）

**交互**：
- 点字或"查看组词" → bottom sheet 弹层显示组词（不跳页）
- 点熟练度按钮 → 标记该字，自动移出清单
- 全部标完 → 完成庆祝动画 → 弹订阅授权卡片
- 订阅授权卡片：开启提醒 / 以后再说

### 3.4 字卡库

**定位**：所有字一目了然，可管理

**页面结构**：
1. **顶部导航**：标题"字卡库" + 右上角"+ 录入"
2. **筛选 tab**：全部 / 待复习 / 已掌握（带数量）
3. **字卡列表**：
   - 每条：熟练度圆点（红/黄/绿）+ 字/词 + 类型标签 + 元信息
   - 点击字/词内容区域 → 弹组词面板
   - 右侧操作按钮：✎ 编辑 + 🗑 删除

**交互**：
- 点字内容 → 组词面板（bottom sheet）
- 点 ✎ → 编辑面板（bottom sheet）：改内容 + 改熟练度 + 删除
- 点 🗑 → 删除（带二次确认）
- 点筛选 tab → 切换列表
- 点右上角"+ 录入" → 录入页

### 3.5 设置页

**定位**：只有三件事，简单直接

**页面结构**：
1. **顶部导航**：标题"设置"
2. **认字日**：周一~周日圆形按钮选择（选中为主色填充）
3. **提醒**：
   - 认字提醒开关（大 Switch）
   - 提醒时间（picker）
   - 提醒额度状态（剩余 N 次，点击补充）
4. **孩子**：孩子昵称（可选）
5. **关于**：版本号

**交互**：
- 点认字日圆形按钮 → 切换选中/取消
- 拨动提醒开关 → 开/关
- 点提醒时间 → 时间 picker
- 保存时同步本地 + 云端

## 四、弹层组件

### 4.1 组词面板（bottom sheet）
- **触发**：复习页点字/"查看组词"、字卡库点字内容
- **展示**：底部滑出，圆角顶部 + 把手
- **内容**：大字 + 拼音 + 常用组词标签（横向排列，自动换行）
- **关闭**：点遮罩 / 点"关闭"按钮
- **共用**：复习页 + 字卡库调用同一组件

### 4.2 编辑字卡面板（bottom sheet）
- **触发**：字卡库点 ✎ 按钮
- **展示**：底部滑出
- **内容**：内容输入框 + 熟练度三档选择 + 删除/保存按钮
- **关闭**：点遮罩 / 保存 / 删除

### 4.3 订阅授权卡片
- **触发**：复习页全部标完后，完成庆祝动画之后
- **展示**：复习完成区下方内嵌卡片
- **内容**："开启认字提醒？" + 说明 + 开启提醒/以后再说按钮
- **时机**：用户刚完成正反馈，授权意愿最高

## 六、交互规范

### 6.1 触控反馈
- 按钮点击：scale(0.93-0.96) 缩放反馈
- 卡片点击：scale(0.98) 轻微缩放
- 所有可点击元素：active 态视觉变化

### 6.2 弹层动画
- Bottom sheet：从底部滑入，300ms ease
- 遮罩：渐显

### 6.3 状态切换
- 熟练度按钮：选中后填充对应颜色（红/琥珀/绿）
- 开关：平滑过渡 200ms
- Toast：底部浮出，2秒自动消失
