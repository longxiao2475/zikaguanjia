## 一、产品定位与简介

**名称**：字卡管家
**类型**：微信小程序（个人主体）
**定位**：面向幼儿园阶段孩子家长的个人字卡复习管理工具
**简介**：字卡管家帮家长用语音、手输等方式快速记录孩子学过的字/词卡，按熟练度和遗忘周期自动排出每日待复习清单，并在认字日提醒家长今天该认字——全程家长操作，孩子不碰屏幕，专注用实体字卡互动。认字时点开任一字即可查看组词，方便讲解。
**核心价值**：记录只是手段，真正卖的是**"替家长做复习调度 + 守住认字节奏"**——不用家长自己判断今天抓哪几个字，到点提醒不漏练，进步看得见。

## 二、目标用户与场景

- **用户**：幼儿园孩子（约 3-6 岁）的家长，本人即使用者；MVP 单家长单孩子
- **老师角色**：不在 MVP。家长（单孩子自用）与老师（多学生管理/布置/汇总）是不同产品形态，老师场景未来单独立项，不混入家长工具
- **核心约束**：孩子不看屏幕；家长一手抱娃一手操作，需高效、单手可完成

### 使用场景（2 主场景 + 日常管理）

- **场景A 认字前**：点进小程序看"今天该复习哪些字 / 重点抓哪几个"（今日待复习清单，按优先级排好；打开即醒目提示，承担被动兜底提醒职责）
- **场景B 认字后**：录入今天新学的字 + 给复习过的字标熟练度/认字次数；认字讲解时点字查看组词
- **日常管理（非场景，随时）**：字卡库查看/编辑/删除、设置认字日与提醒

## 三、MVP 范围（P0 必做）

1. 录入：语音录入（一次一个，主力，走 Path B 录音+云端 ASR）+ 手动输入（兜底）
2. 字卡库：列表、筛选（全部/待复习/已掌握）、编辑、删除
3. 复习提醒：双重提醒（主动推送订阅消息 + 首页被动兜底）+ 今日待复习清单（按优先级排序）
4. 复习打卡：批量标熟练度（3档）+ 自动更新上次复习时间/累计复习次数
5. 组词：点击字卡查看该字的常用组词（内置词典自动提供）
6. 设置：认字日、提醒时间、提醒开关

## 四、功能详细说明

### 4.1 录入
- **语音录入（主力）**：按住大圆按钮说话说一个字/词，录音→云端 ASR 识别→展示确认后保存。一次一个。
  - 技术路径：Path B（前端 wx.getRecorderManager() 录音 + 云函数 asrProxy 调腾讯云 ASR）。因个人主体不能用微信同声传译插件。功能体验与插件路径一致，多一个轻后端中转。ASR 免费额度 MVP 单用户足够。
  - 抽象层设计：voice.js STRATEGY='cloud'，未来升级主体改一行切回插件路径。
- **手动输入（兜底）**：直接打字，处理个别增改/纠错。也作为语音识别次数超限时的兜底。
- **拍照 OCR**：放 P2（最后做），用于一次性导入一整套卡。
- **卡片字段**：内容、类型（单字/词语）、语言（中文，英文 P2）、录入时间、熟练度、上次复习时间、累计复习次数、来源（新学/已学过）。
- **默认熟练度**：新学字卡→默认"不熟"；历史字卡（补录已学过的）→默认"一般"。实现：录入时快捷开关"新学/已学过"，默认"新学"；批量补录历史卡时整体默认"一般"（交互由 Designer 细化）。
- **去重**：同字/词已存在则提示合并/跳过。

### 4.2 字卡库
- 列表展示全部字卡，筛选（全部/待复习/已掌握），按熟练度/上次复习时间排序
- 可编辑（改内容/熟练度，弹出 bottom sheet 编辑面板）、删除（🗑 按钮，带二次确认）
- 点字卡内容区域弹组词面板（与编辑/删除按钮分区域不误触）

### 4.3 复习提醒（双重保障）
**主动推送**：
- 周期提醒：设每周认字日（如二四六）+ 提醒时间，到点微信订阅消息推送"今天该认字啦 + 今日重点 N 个字"
- 走一次性订阅消息"攒量"模式（个人主体可用，不区分主体类型）：复习打卡后弹订阅授权，攒够额度到点推送
- 风险：用户连续多天不打开→订阅额度耗尽→主动推送断
**被动兜底**（永远不断）：
- 打开小程序首页即见醒目提示"今天该认字啦 + 今日重点 N 个字"（认字日 + 有待复习时显示顶部渐变 banner）
- 不依赖订阅额度，只要打开就看到，保护核心价值"守住认字节奏"
**提醒额度引导**（保留，微信平台限制决定必须做）：
- 复习打卡后立即弹订阅授权（自然时机，一次申请多条）
- 首页显示"剩余提醒 N 次"
- 额度≤2 时醒目 banner 提示"提醒额度不足，打开即续订"

### 4.4 复习打卡
- 复习中：家长拿实体字卡陪孩子，小程序仅后台记录不打断
- 复习后：对今日待复习字批量标熟练度（熟练/一般/不熟）；标完自动更新上次复习时间=今天、累计复习次数+1
- 全部标完→完成庆祝动画→弹订阅授权（补充提醒额度）

### 4.5 组词
- 在字卡详情/复习清单中点击任一单字，展示该字常用组词（如"大"→大小/大人/大家）
- 展示形式：bottom sheet 弹层（不跳页），复习页+字卡库共用组件
- **数据来源**：内置常用组词词典（cnchar-words，分包按需加载），覆盖常用汉字组词，开箱即用
- **家长补充**（方案B，放 P1）：家长可对个别字自定义补充/覆盖组词
- 内置词典数据来源与集成成本待 Tech Lead 评估（骨架已用示例数据，待补全 3000 字）

### 4.6 设置
- 认字日（每周哪几天，圆形按钮选择）、每日提醒时间、提醒总开关、孩子信息（可选，MVP 单孩子）
- 保存时同步本地 + 云端（syncSettings 云函数）

## 五、熟练度模型（3档）

| 档位 | 定义 |
|---|---|
| 不熟 | 读不出 / 不认识 |
| 一般 | 提示后能认，或时认时不认 |
| 熟练 | 一眼能认，稳定 |

## 六、提醒与优先级逻辑（轻量间隔重复）

**今日待复习判定**：
- 不熟 → 每个认字日都进待复习
- 一般 → 距上次复习 ≥ 2 天进待复习
- 熟练 → 距上次复习 ≥ 7 天进待复习

**清单排序**：不熟 > 一般 > 熟练；同档内距上次复习越久越靠前

**漏卡补卡**：当天未打卡、次日提醒补上 → 放 P1，MVP 不做

## 七、额度机制（终稿定论）

| 机制 | MVP 是否做 | 理由 |
|------|-----------|------|
| 字卡总数限制 | ❌ 不做 | 卡核心功能(记录新学字) + MVP 单用户本地存储无成本 + "复习增加额度"激励在自用工具多余。留到多用户/商业化时设计 |
| 提醒额度引导（订阅消息攒量） | ✅ 保留 | 微信平台限制决定必须做，引导用户补充订阅额度 |
| 首页被动兜底（打开即提醒） | ✅ 保留 | 永远不断的提醒保障，成本为零 |
| 广告扩容 | ❌ MVP 不做 | P1+ 考虑 |

## 八、信息架构 / 页面结构

```
首页（今日状态 + 快捷入口 + 被动兜底提醒）
├── 认字日提醒 banner（"今天该认字啦 + 今日重点 N 个字"）
├── 今日待复习 / 今日计划
├── 快速录入按钮（语音为主）
├── 学习概览（总字数、已掌握、待复习）
└── 提醒额度≤2 时预警 banner（引导续订）

字卡库
├── 全部 / 待复习 / 已掌握 筛选
├── 按熟练度/时间排序
├── 每条字卡：✎编辑(弹层) + 🗑删除
└── 点字卡内容弹组词面板

复习页
├── 今日优先清单
├── 点击单字查看组词（bottom sheet 弹层）
├── 三档熟练度大按钮
└── 全部标完→完成庆祝→弹订阅授权

设置
├── 认字日设置（圆形按钮）
├── 提醒开关/时间
├── 提醒额度状态显示
└── 孩子信息（可选）
```

## 九、视觉与交互方向（与 Designer 对齐）

- 基调：温暖、干净、高效；柔和主色 + 留白 + 圆角卡片
- 字号偏大清晰；底部主操作区单手可达；语音按钮做成醒目大圆按钮（120px）
- 不做儿童游戏化、积分排行榜——这是家长工具
- 硬约束（用户原话）：设计得易于操作、简洁，低认知负担，不然用户不知道怎么操作
- 每屏一个焦点、少步骤（录入两步存、复习点一下标好）、无隐藏菜单、无复杂交互
- 组词弹层统一 bottom sheet，复习页+字卡库共用组件

## 十、非功能 / 技术方向

- 微信小程序原生开发（WXML/WXSS/JS）
- 后端：微信云开发（Cloud Base），免运维免备案，定时触发器发订阅消息，免费额度 MVP 单用户够
- 语音识别：Path B 录音 + 云函数 asrProxy 调腾讯云 ASR（个人主体）
- 微信一次性订阅消息做提醒（攒量模式，需用户授权订阅）
- 内置组词词典：cnchar-words 分包按需加载
- 数据本地存储优先（wx.setStorageSync，单用户）
- 云函数：syncSettings（同步设置+管理订阅配额）、sendReminder（定时触发发提醒）、asrProxy（语音识别代理 Path B）
- 开工前配置项：云开发环境 ID、订阅消息模板 ID（PM 跟进申请）、腾讯云 ASR 密钥、组词词典数据补全 3000 字

## 十一、P1 / P2 规划

**P1**：语音批量录入（一次说多个）、漏卡补卡/顺延提醒、学习概览统计（掌握率、连续认字天数）、组词家长自定义补充/覆盖、广告扩容机制（字卡总数额度 + 看广告解锁）
**P2**：拍照 OCR 批量导入、英文单词、多孩子、艾宾浩斯级间隔重复、字卡分组标签

## 十二、验收标准（MVP）

- [ ] 语音录入一个字/词→录音→云端识别→确认→入库，默认熟练度按新学/已学过正确赋值
- [ ] 手动输入增改字卡可用
- [ ] 字卡库可筛选全部/待复习/已掌握、可编辑(弹层改内容/熟练度)、可删除(带二次确认)
- [ ] 设认字日+提醒时间→到点收到订阅消息且含今日重点数
- [ ] 首页认字日+有待复习时显示醒目提醒 banner（被动兜底）
- [ ] 今日待复习清单按优先级正确排序
- [ ] 复习后批量标熟练度→上次复习时间/累计次数正确更新
- [ ] 点击单字→展示内置词典的常用组词（弹层不跳页）
- [ ] 提醒额度≤2 时首页显示预警 banner 引导续订
- [ ] 全程孩子不看屏幕，家长单手可完成主流程
