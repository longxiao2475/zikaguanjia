# Day 4–Day 5 Review and Reminder Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成复习打卡、组词 Bottom Sheet、设置保存、订阅额度、定时提醒和首页双 Banner，并提供无需部署即可运行的自动测试。

**Architecture:** 前端只通过云函数访问权威数据；复习、订阅额度和提醒分别由 `reviewService`、`subscriptionService`、`sendReminder` 管理，孩子设置继续由 `syncSettings` 管理。事务和消息发送器通过 repository / dependency injection 与纯业务逻辑隔离，Node 测试使用内存实现验证原子性、幂等和失败分支。

**Tech Stack:** 微信小程序原生 JavaScript/WXML/WXSS、CloudBase `wx-server-sdk`、Node.js `node:test`、开发期 `pinyin-pro` 数据生成工具。

```js
function validateCustomWord(content, input) {
  const word = normalizeWord(input);
  if (!word) return { ok: false, code: 'CUSTOM_WORD_REQUIRED', message: '请输入组词' };
  if (Array.from(word).length > 12) return { ok: false, code: 'CUSTOM_WORD_TOO_LONG', message: '组词不能超过 12 个字' };
  if (Array.from(content).length === 1 && !word.includes(content)) {
    return { ok: false, code: 'CUSTOM_WORD_MISMATCH', message: `组词需要包含“${content}”` };
  }
  return { ok: true, word };
}
```

`mergeWords` 先放自定义词，再放 `大` 的固定推荐词，再放词典原始词，使用 Set 去重。
