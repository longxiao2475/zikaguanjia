# 字卡库统一筛选与上次复习时间设计

## 目标

- 将字卡库的字卡名称、状态、分类和未复习时间筛选收拢为一个符合微信小程序习惯的统一筛选卡片。
- 将“+ 录入”和“选择复习”两个操作按钮的右边缘统一对齐。
- 在首页和字卡库明确展示每张字卡的“上次复习”信息。
- 支持筛选至少 7 天或至少 30 天没有复习的字卡，并将从未复习的字卡包含在结果中。

## 页面信息结构

### 字卡库头部

- 第一行左侧保留标题和说明，右侧保留“+ 录入”。
- 第二行左侧显示当前结果数量，右侧保留“选择复习”。
- 两个操作按钮使用相同的右侧约束：`margin-left: auto`、`margin-right: 0`、不继承原生按钮自动外边距，确保右边缘落在同一条垂直线上。
- 两个按钮不强制等宽；保持“+ 录入”较短、“选择复习”较宽，但高度、圆角和字号保持同一层级。

### 统一筛选卡片

所有筛选控件放入一个 `surface-card` 容器，内部使用轻分隔线和固定纵向间距，不再让搜索框、分类按钮和状态标签各自成为独立卡片。

筛选卡片自上而下包含：

1. 搜索行：原生输入框，提示“搜索字或词”，有内容时显示“清除”。
2. 状态行：标题“状态”，使用三等分分段按钮展示“全部 / 待复习 / 已掌握”及数量。
3. 未复习行：标题“未复习”，使用三等分分段按钮展示“不限 / 7天未复习 / 30天未复习”。三个选项单选。
4. 分类行：整行可点击，左侧显示“分类”，中间显示当前分类摘要，右侧显示小程序常见的右箭头；继续打开现有多选分类弹层。
5. 操作行：仅当任一非默认筛选生效时显示筛选摘要与“清空筛选”。

交互控件保持至少 `88rpx` 的触摸高度，不使用横向滚动标签，不引入桌面网页式下拉菜单。选中态同时使用背景色、文字颜色和边框变化，不能只依赖颜色深浅。

## 筛选规则

- 字卡名称、状态、分类和未复习时间之间使用 AND 关系。
- 多个分类之间继续使用 OR 关系；“未分类”继续作为可组合选项。
- 未复习时间使用 `reviewAgeDays` 表示：`0` 为不限，`7` 为至少 7 天，`30` 为至少 30 天。
- 阈值包含当天边界：7 天前最后复习的字卡属于“7天未复习”，30 天前最后复习的字卡属于“30天未复习”。
- `lastReviewAt` 为空时视为无限久未复习，因此同时属于 7 天和 30 天筛选结果。
- 天数继续使用现有上海时区自然日算法，避免北京时间跨日时出现少算一天。
- 状态数量在名称、分类和未复习时间条件确定的范围内计算；当前选中的状态本身不改变三个状态数量，便于用户比较和切换。
- 修改或删除字卡后，前端可进行即时可见性判断，随后仍重新请求第一页，以云端组合筛选结果为准。

## 接口与数据流

- `cardService.list` 新增可选参数 `reviewAgeDays`，只接受 `0`、`7`、`30`，非法值按 `0` 处理。
- 云端处理顺序为：活动字卡 → 分类 → 关键词 → 未复习时间 → 状态 → 分页。
- `counts` 基于分类、关键词和未复习时间过滤后的集合计算 `all`、`due`、`mastered`。
- 小程序 `utils/card.js` 透传 `reviewAgeDays`；只在所有筛选均为默认值时复用现有全部列表缓存。
- 字卡库页面新增 `reviewAgeDays` 和时间筛选定义；切换时间条件时清空当前分页并加载第一页。
- 首页无需新增接口，继续使用今日计划返回的 `lastReviewAt` 装饰字卡。

## 上次复习信息

- 复用现有 `formatLastReview` 相对时间算法，但在页面文案中明确增加标签。
- 首页显示：`上次复习：今天`、`上次复习：昨天`、`上次复习：7天前`或`上次复习：从未复习`。
- 字卡库元信息显示：`不熟 · 上次复习：7天前 · 已复习 3 次`。
- 为避免卡片信息过长，保持单行省略；分类标签仍单独占一行。
- 纯格式化函数返回简短时间值，不把“上次复习：”写进底层函数，页面可按不同上下文组合文案。

## 空状态与错误处理

- 任一筛选生效且无结果时，标题显示“没有符合筛选条件的字卡”，正文提示调整或清空筛选，并提供“清空筛选”按钮。
- 分类加载失败时统一筛选卡仍可使用名称、状态和时间筛选；分类行显示“分类加载失败”和“重试”。
- 字卡列表加载失败继续显示现有错误条和重试入口，当前筛选条件不丢失。
- 清空筛选会同时恢复空关键词、全部状态、不限时间和全部分类，并只触发一次列表刷新。

## 测试

- 复习时间纯函数覆盖 7 天、30 天、阈值前一天、上海时区跨日和从未复习。
- `cardService.list` 覆盖时间筛选、从未复习包含、与关键词/分类/状态组合、动态数量和分页。
- 前端 API 覆盖 `reviewAgeDays` 参数透传与缓存条件。
- 字卡库页面覆盖时间选项切换、组合请求、清空全部筛选、编辑后可见性和空状态判断。
- 首页与字卡库结构测试覆盖明确的“上次复习：”标签、统一筛选卡、三个时间选项以及两个右对齐按钮。
- 微信开发者工具操作测试覆盖：搜索、状态切换、7 天筛选、30 天筛选、分类多选、组合筛选、清空筛选、进入选择复习模式和两个按钮右边缘对齐。

## 非目标

- 不提供自定义天数输入、日期范围选择或复习次数筛选。
- 不改变现有复习调度规则和待复习判定。
- 不新增分类层级或分类删除功能。
- 不改变卡片排序规则；筛选后的结果继续按熟练度和最久未复习优先排序。
