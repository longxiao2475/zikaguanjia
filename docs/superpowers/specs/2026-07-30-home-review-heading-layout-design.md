# 首页待复习标题布局设计

## 目标

让首页“全部字卡”按钮与页面右侧对齐，并避免“不熟优先，同档越久没复习越靠前”被按钮挤压成不自然的两行。

## 方案

采用两列 Grid：左侧为可收缩的标题文案区域，右侧为固定宽度的“全部字卡”按钮。标题位于左上，按钮位于右上；说明文字位于第二行并横跨两列，因此可以使用整行宽度自然显示。

不缩小字号、不截断说明文字、不使用绝对定位。按钮保留原有点击行为和小程序文字按钮视觉。

## 验收

- “全部字卡”右边缘与首页内容区右边缘对齐。
- “今日待复习”和“全部字卡”处于同一行。
- 说明文字位于下一行，正常手机宽度下不被按钮挤压换行。
- 首页其他卡片、复习入口和跳转行为不变。
