# 字卡交互、搜索与临时复习队列设计

> 日期：2026-07-26  
> 范围：修复 Day 4 / Day 5 联调发现的交互缺陷，并补齐字卡库汉字片段搜索与多选复习能力。

## 1. 目标

本轮交付解决以下问题：

1. 复习页和字卡库点击字卡后可以稳定打开拼音与组词弹层。
2. 首页“总字数 / 已掌握 / 待复习”三个统计卡可进入对应字卡库筛选。
3. 字卡库支持按汉字或词语片段搜索。
4. 字卡库支持多选，并将选中字卡加入一次性的本次复习队列。
5. “已学过且从未复习”的字卡不会永久脱离自动复习计划。
6. 设置页完整显示周一至周日并支持多选。
7. 删除面向开发阶段的“字卡管家 MVP · Day 5”提示。

拼音搜索不在本轮实现，记录到后续计划。

## 2. 已确认的根因

### 2.1 拼音和组词弹层无响应

开发者工具报错：

```text
Component is not found in path "components/word-sheet/index"
```

页面事件处理函数已经存在，但自定义组件没有成功解析，因此点击后即使更新了 `showWordSheet`，也没有可展示的弹层。现有自动测试只检查文件和 JSON 字符串是否存在，没有验证微信组件路径能否被真实构建解析。

### 2.2 首页统计数字不可点击

三个概览卡片只有展示数据，没有 `bindtap` 事件，也没有向字卡库传递筛选条件的逻辑。

### 2.3 历史字卡无法进入自动复习

“已学过”字卡初始熟练度为 `normal`，同时 `lastReviewAt` 为 `null`。现有调度规则仅允许 `lastReviewAt` 为空且熟练度为 `unfamiliar` 的字卡立即进入计划，导致这类 `normal` 字卡永远无法达到“距上次复习 ≥ 2 天”的条件。

### 2.4 认字日只显示部分选项

数据层已经定义周一至周日七个选项，问题在于当前七列 Grid 布局在开发者工具所用基础库中发生异常收缩或裁切。该区域改用兼容性更稳定的 Flex 换行布局。

## 3. 方案选择

采用临时复习队列，不新增数据库集合，也不在 `cards` 上增加长期状态字段。

选择理由：

- 多选行为只影响即将开始的一轮复习，不应改变字卡的长期调度状态。
- 本轮完成后仍由现有 `reviewService.complete` 更新熟练度、复习时间和次数。
- 不引入队列过期、跨日清理、并发覆盖等持久化状态问题。
- 保持云数据库作为字卡和复习结果的权威数据源；临时选择只属于页面导航上下文。

## 4. 页面与交互设计

### 4.1 首页

三个统计卡增加明确点击行为：

| 统计卡 | 目标页面 | 默认筛选 |
|---|---|---|
| 总字数 | 字卡库 | `all` |
| 已掌握 | 字卡库 | `mastered` |
| 待复习 | 字卡库 | `due` |

首页通过单用途轻量缓存写入目标筛选，随后使用 `wx.switchTab` 进入字卡库。字卡库在 `onShow` 消费该筛选并立即加载对应列表，消费后清除，避免后续进入仍被旧状态覆盖。

### 4.2 字卡库搜索

字卡库标题区下方增加搜索框：

- 输入汉字或词语片段，例如“礼”匹配“礼物”，“吃”匹配“吃饭”。
- 搜索执行去首尾空格、NFKC 标准化和移除内部空白，与字卡入库标准化一致。
- 输入采用短防抖，避免每输入一个字符都立即请求云函数。
- 清空搜索后恢复当前筛选的完整列表。
- 搜索与 `all / due / mastered` 筛选同时生效。
- 无结果时显示“没有找到相关字卡”，保留清空搜索入口。

MVP 的字卡规模较小，`cardService.list` 继续读取孩子的活动字卡后在服务层执行内容片段匹配、调度筛选、排序和分页。后续数据规模扩大时，再迁移到专用检索字段或搜索服务。

### 4.3 字卡库多选

字卡库增加“选择复习”入口：

1. 点击后进入选择模式，每张字卡显示选择框。
2. 点击字卡的选择区域切换选中状态；点击内容详情区域仍打开拼音和组词弹层，避免功能互相覆盖。
3. 页面底部固定操作栏显示“已选 N 张”和“开始复习”。
4. 未选择任何字卡时，“开始复习”不可用。
5. 支持跨筛选、跨搜索保留本页会话内已选 ID；重新打开小程序不恢复选择。
6. 点击取消或成功进入复习页后清空选择状态。

### 4.4 临时复习队列

用户点击“开始复习”后：

1. 字卡库把选中的字卡 ID 写入一次性临时缓存。
2. 跳转复习页时带上 `source=manual` 标识。
3. 复习页加载云端今日计划，同时读取临时选择。
4. 按“系统今日计划在前、手动选择在后”的顺序合并，并按 `_id` 去重。
5. 若某个手动选择的字卡已被删除或无权访问，云端补查时忽略该项并提示用户。
6. 复习页成功建立本轮状态后立即消费临时队列，防止返回页面或重复进入时再次注入。
7. 整轮提交继续调用 `reviewService.complete`，不区分自动字卡和手动字卡。

临时队列只决定本轮显示哪些字卡，不写入 `cards`、`children` 或新集合。

### 4.5 自动调度修正

保持 PRD 约定：

- 不熟：每个认字日进入待复习。
- 一般：距上次复习至少 2 天进入。
- 熟练：距上次复习至少 7 天进入。

补充首次复习规则：任何活动字卡只要 `lastReviewAt` 为空，都应该进入首次复习计划。这样“已学过”只决定初始熟练度为“一般”，不会让字卡永久失去第一次复习机会。

前端纯函数和云端 `cardService/review.js` 必须使用完全一致的规则。

### 4.6 字卡详情弹层

- 将组件引用改为开发者工具可稳定解析的相对路径，并增加构建级结构校验。
- 复习页点击主字卡打开弹层。
- 字卡库点击内容区域打开弹层；选择框和后续编辑操作使用独立点击区域。
- 弹层继续显示内容、拼音、内置组词、自定义组词输入。
- 保存自定义组词后更新当前页面列表和弹层卡片快照。

### 4.7 设置页

- 周一至周日七个圆形按钮使用 Flex 换行/等宽布局，不依赖七列 Grid。
- 支持任意多选，但至少保留一天。
- 继续使用现有 `syncSettings.saveSettings` 保存。
- 删除底部“字卡管家 MVP · Day 5”开发阶段文案。

## 5. 数据与接口变化

### 5.1 `cardService.list`

请求增加可选字段：

```js
{
  childId: 'child_xxx',
  filter: 'all',
  keyword: '礼',
  page: 1,
  pageSize: 20
}
```

服务端返回结构保持不变。`counts` 表示未应用关键字时三个分类的总数，避免搜索过程中顶部分类数量来回变化；`total` 和 `items` 表示应用当前筛选与关键字后的结果。

### 5.2 `cardService.getByIds`

复习页使用当前孩子 ID 和临时队列中的字卡 ID 补查权威字卡：

```js
{
  childId: 'child_xxx',
  cardIds: ['card_a', 'card_b']
}
```

服务端只返回属于当前用户、当前孩子且状态为 `active` 的字卡，并保持请求 ID 的顺序。最多接收 50 个 ID，重复 ID 去重。这样复习页不会依赖可能过期的本地字卡快照。

### 5.3 临时缓存

新增单用途缓存键，仅保存本次复习选择：

```js
{
  cardIds: ['card_a', 'card_b'],
  createdAt: 1785030000000
}
```

缓存被复习页读取后立即删除；创建时间超过 30 分钟的数据视为失效并清除。

### 5.4 复习提交

`reviewService.complete` 的请求和事务模型不变：

```js
{
  childId: 'child_xxx',
  items: [
    { cardId: 'card_a', proficiency: 'normal' }
  ]
}
```

## 6. 错误处理

- 搜索失败：保留关键字和现有列表，显示可重试提示。
- 手动队列部分字卡失效：忽略失效项，提示“部分字卡已不可用”。
- 手动队列全部失效且今日计划为空：显示空状态并返回字卡库入口。
- 组件无法加载：构建测试必须失败，不允许静默退化为点击无响应。
- 临时缓存解析失败或过期：清除缓存，继续使用正常今日计划。
- 复习提交失败：沿用现有结果保留和重新提交能力。

## 7. 测试设计

### 7.1 纯函数与服务测试

- `normal + lastReviewAt=null` 会进入首次复习。
- 前端和云端调度对同一组字卡返回相同结果。
- 关键字标准化、片段匹配、筛选叠加和分页正确。
- 今日计划和手动选择按 ID 合并且顺序稳定。
- 临时队列写入、读取、消费、过期清理正确。

### 7.2 页面结构与交互测试

- `word-sheet` 相对组件路径对应真实文件。
- 复习页和字卡库都绑定打开、关闭弹层事件。
- 首页三个统计卡绑定对应筛选导航事件。
- 字卡库包含搜索输入、选择模式、选中数量和开始复习事件。
- 设置页包含七个选项，样式不再使用七列 Grid。
- 页面中不再包含 `MVP · Day 5` 文案。

### 7.3 微信开发者工具验收

1. 编译后控制台不再出现 `word-sheet` 组件路径错误。
2. 复习页点击字卡能看到拼音和组词。
3. 字卡库点击字卡内容能看到同一弹层。
4. 搜索“礼”只显示包含“礼”的字卡，清空后恢复列表。
5. 多选两张非今日待复习字卡，开始后与今日计划合并且不重复。
6. 完成本轮后字卡复习次数和熟练度正确更新。
7. 首页三个数字分别打开正确筛选。
8. 设置页完整显示周一至周日，能保存任意合法组合。
9. 页面不再显示 Day 5 开发提示。
