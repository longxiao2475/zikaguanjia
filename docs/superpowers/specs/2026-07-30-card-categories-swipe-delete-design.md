# 字卡分类与左滑删除设计

## 目标

为每个孩子提供一套可维护的字卡分类，并允许录入、编辑和字卡库筛选时多选分类；同时在字卡库普通浏览模式中加入左滑删除入口，复用现有软删除和二次确认流程。

## 分类模型

- 新增 `categories` 集合，分类归属于 `childId`，字段包含 `name`、`normalizedName`、`sortOrder`、`isDefault`、`status`、创建与更新时间。
- 字卡新增 `categoryIds: string[]`。一张字卡可属于多个分类，最多 10 个；空数组表示“未分类”。
- 首次读取分类时为孩子生成默认分类；已有任何分类记录时不重复生成。
- 默认分类与自定义分类都允许改名。分类名称执行 NFKC、去除首尾空白、最长 12 个字符，并在同一孩子下保持唯一。
- 本阶段支持新增和改名，不加入分类删除，避免处理被大量字卡引用时的迁移歧义。

## 默认分类

交通工具、食品、身体部位、家具、植物、动物、水果、蔬菜、服饰、学习用品、玩具、日常用品、家庭成员、人物职业、颜色、数字、形状、方位、时间、动作行为、情绪感受、自然天气、建筑场所、节日文化。

## 分类交互

- 录入页在“这张字卡是”之后显示所属分类，可多选；保存成功后保留选择，便于连续录入同类字卡。
- 编辑弹层显示当前分类，可修改后与内容、熟练度一起保存。
- 共用 `category-picker` 组件展示选择态和管理态。管理态通过可编辑原生弹窗完成新增、改名。
- 字卡库增加分类筛选入口。筛选弹层支持多选真实分类和“未分类”。分类之间是 OR 关系，再与关键词和熟练度筛选做 AND 组合。
- 字卡列表显示最多两个分类标签，更多分类显示“+N”。
- 旧字卡缺少 `categoryIds` 时按空数组处理，无需批量迁移。

## 分类服务

- 新增 `categoryService` 云函数，提供 `list`、`create`、`update`。
- `cardService` 创建和更新时校验分类均属于当前孩子且为活动状态。
- `cardService.list` 接收 `categoryIds` 与 `includeUncategorized`，先按分类范围过滤，再计算全部、待复习、已掌握数量。
- 前端分类 API 缓存分类列表；分类新增或改名后立即更新缓存。

## 左滑删除

- 仅普通浏览模式启用；进入选择复习模式时关闭所有已展开卡片并禁用滑动。
- 卡片记录触摸起点和终点。当水平位移大于 36px 且大于垂直位移时判定为滑动：左滑展开，右滑收起。
- 展开状态使用 CSS 固定移动 `144rpx`，不在移动过程中持续 `setData`，避免滚动卡顿。
- 同时只能展开一张卡片。点击已展开卡片只收起，不打开详情。
- 点击删除后显示现有确认弹窗，确认后调用现有软删除 API；编辑弹层中的删除入口继续保留。
- 滑动删除按钮提供 `aria-role="button"` 和明确标签，保证手势不是唯一删除路径。

## 错误处理

- 分类加载失败时页面仍可录入和浏览，分类区域显示重试提示。
- 新增或改名失败时保留分类弹层和用户当前选择。
- 分类失效或越权由云端拒绝，字卡保存不写入部分数据。
- 删除失败时卡片恢复关闭状态并显示提示，列表数据保持不变。

## 测试

- 服务层覆盖默认分类生成、名称校验、重复校验、归属校验、字卡分类保存与组合筛选。
- 前端 API 覆盖分类缓存和请求参数。
- 页面层覆盖录入/编辑分类 payload、多分类筛选、旧字卡未分类兼容。
- 纯函数覆盖横纵手势判断、展开/关闭阈值和单卡展开。
- 结构测试覆盖组件注册、分类入口、三个分类熟练度按钮、滑动容器和删除操作。

## 非目标

- 不自动判断字卡应属于哪个分类。
- 不提供分类层级、颜色自定义、图标、删除、合并和拖拽排序。
- 不改变复习调度规则。
