# 首页待复习字卡分批选择设计

> 日期：2026-07-31  
> 范围：首页“今日待复习”区域增加本批复习字卡管理能力。

## 1. 目标

“待复习”表示系统根据调度规则判断出的全部候选字卡，但用户每次不一定复习全部候选字卡。本功能允许用户直接在首页把待复习字卡分成若干批次，选择当前一批后开始复习；未选择的字卡继续保留在待复习列表中，供后续批次使用。

本功能不改变字卡熟练度规则、待复习判断规则和复习完成提交逻辑。

## 2. 已确认方案

采用首页原地进入选择模式的方案：

1. 首页“今日待复习”区域增加“管理本次复习”操作。
2. 点击后，当前待复习卡片进入多选状态，不跳转字卡库。
3. 用户点击整张待复习卡片切换选中状态，选中卡片显示符合微信小程序风格的明确勾选效果。
4. 选择操作区提供“全选/取消全选”“退出管理”“开始本批复习”。
5. 操作区显示“已选 N 张”；未选字卡时“开始本批复习”不可用。
6. 默认不选中任何字卡，由用户主动组成当前批次。

原有普通“开始复习”入口保留，仍用于复习系统给出的全部待复习字卡。

## 3. 复习队列语义

临时复习队列增加显式模式，避免现有不同入口互相影响：

```js
{
  cardIds: ['card_a', 'card_b'],
  mode: 'replace',
  createdAt: 1785460000000
}
```

- 首页“开始本批复习”写入 `mode: 'replace'`：复习页只加载本批选中的字卡，不再自动合并系统全部待复习字卡。
- 字卡库现有“选择复习”继续使用 `mode: 'append'` 或兼容缺省模式：保持“系统计划 + 手动选择”的既有行为。
- 普通首页“开始复习”不写入手动队列，继续加载系统完整待复习计划。
- 复习页成功建立本轮状态后立即消费临时队列，防止返回或重复进入时再次注入。

## 4. 页面状态与数据流

首页在本次页面会话中维护：

- 是否处于选择模式；
- 当前选中的字卡 ID 集合；
- 选中数量及是否已经全选。

流程如下：

1. 首页按现有逻辑加载今日待复习列表。
2. 用户进入选择模式，初始选中集合为空。
3. 用户选择若干字卡，或使用全选/取消全选。
4. 点击“开始本批复习”后，首页将所选 ID 按当前列表顺序写入一次性临时队列，并跳转复习页。
5. 复习页识别 `replace` 模式，只从云端补查并加载所选有效字卡。
6. 本批完成或退出后返回首页，首页重新计算待复习列表。
7. 已完成字卡按现有复习结果更新；未选择字卡没有任何数据变化，仍留在待复习列表。

选择状态只属于当前页面会话，不写入字卡数据，不跨小程序重启恢复。

## 5. 交互细节

- 非选择模式下，待复习卡片保持现有点击行为。
- 选择模式下，点击待复习卡片只切换选择，不打开字卡详情，避免一次点击产生两种结果。
- 退出管理时清空本次选中状态，恢复普通卡片交互。
- 待复习列表为空时不显示管理入口。
- 进入选择模式后如果列表发生刷新，移除已经不在有效待复习列表中的选中 ID。
- 操作按钮在窄屏手机上不得横向溢出；使用小程序现有按钮尺寸、圆角、颜色和安全区间距。

## 6. 异常处理

- 点击开始时选择为空：不跳转，并保持按钮禁用状态。
- 部分所选字卡在进入复习页前已被删除或失效：忽略失效字卡，提示“部分字卡已不可用”，继续复习其余字卡。
- 所选字卡全部失效：不回退到系统全部待复习，显示本批无可用字卡，并提供返回首页入口。
- 临时队列损坏或过期：清除队列；对于明确的本批复习入口，不得静默加载全部待复习字卡。
- 写入临时队列或跳转失败：保留首页选择状态并提示重试。

## 7. 测试与验收

### 7.1 自动测试

- 首页进入/退出选择模式和默认未选中状态正确。
- 单选、多选、全选、取消全选及选中数量正确。
- 未选中时开始按钮不可用。
- `replace` 队列只返回所选字卡并保持顺序，不合并系统计划。
- 现有 `append` 队列仍按“系统计划在前、手动选择在后”合并并去重。
- 队列部分失效、全部失效、过期及损坏时行为符合设计。
- 返回首页后，未完成的待复习字卡仍可再次选择。

### 7.2 微信开发者工具操作验收

1. 打开首页，确认“今日待复习”存在管理入口且无按钮溢出。
2. 点击“管理本次复习”，确认所有待复习卡片出现可识别的选择状态。
3. 选择第一批若干字卡，检查选中效果和“已选 N 张”。
4. 验证全选、取消全选、退出管理及重新进入。
5. 点击“开始本批复习”，确认复习页只出现本批所选字卡。
6. 完成第一批并返回首页，确认其余待复习字卡仍在并可组成第二批。
7. 使用普通“开始复习”，确认仍可加载全部系统待复习字卡。
8. 从字卡库使用现有“选择复习”，确认其追加队列行为未被本功能破坏。
9. 使用不同屏幕尺寸检查操作区、按钮、选中标记及底部安全区布局。

## 8. 非目标

- 不新增长期复习清单或跨设备同步的批次。
- 不自动按固定数量分批。
- 不改变待复习排序、熟练度或复习间隔规则。
- 不改变字卡库现有筛选和多选入口的产品语义。
